# The Decline of Deaths of Despair in Italy
This repository provides all materials required to replicate the study published in Population Health Metrics:  “The decline of ‘Deaths of Despair’ in Italy: unveiling this phenomenon in a new context”, Giacomo Lanfiuti Baldi, Andrea Nigri, Sergi Trias-Llimós, and Elisabetta Barbi, (Population Health Metrics, 2025)

# Repository Description

The repository provides all materials required to replicate the study published in Population Health Metrics:

“The decline of ‘Deaths of Despair’ in Italy: unveiling this phenomenon in a new context”
Giacomo Lanfiuti Baldi, Andrea Nigri, Sergi Trias-Llimós, and Elisabetta Barbi
Population Health Metrics (2025)

The paper investigates long-term trends in Deaths of Despair—defined as mortality from suicide, alcohol-related causes, and drug-related causes—in Italy over the period 1983–2018, offering a systematic analysis of a context that differs substantially from those (e.g. the United States) where this concept was originally developed.

Using official cause-of-death data from ISTAT, aggregated by sex, five-year age groups, and Italian macro-regions (NUTS1), the study:

quantifies the contribution of each cause of death to overall mortality using the Potential Gain in Life Expectancy (PGLE) framework;

examines long-run relationships among suicide-, alcohol-, and drug-related mortality through cointegration analysis.

The main findings point to an overall decline in Deaths of Despair in Italy, largely driven by reductions in alcohol-related mortality, and show that the three components do not share a common long-term trend, suggesting distinct underlying dynamics.

# Repository Contents

The repository includes:

# Data
Cleaned and aggregated datasets used in the analysis.
Raw cause-of-death data are not publicly available and must be requested directly from ISTAT.

# Analysis code
Scripts for data cleaning, indicator construction (including PGLE), time-series analysis, and cointegration testing.

# Figures
Code to reproduce all figures and tables presented in the paper.
